What this checks

RUNE checks supplied metadata and profile compatibility. Field constraints and invariant text are retained declarations, not executed checks. This page does not compile Rust, scan source, inspect a live runtime, authorize actions or execute a host. Inputs stay in this browser worker.

Unknown fields are listed and omitted from normalized output. Keep your original input when round-tripping. Some generated summaries intentionally omit detail; compare the normalized descriptor before adopting them.
